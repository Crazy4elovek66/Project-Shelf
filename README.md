# Project Shelf

Одностраничный лендинг-портфолио для проекта Project Shelf: личный хаб IT-проектов, MVP и технических экспериментов.

## Стек

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react

## Запуск

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Сборка

```bash
npm run build
```

## Структура

- `src/app` - маршруты Next.js и глобальные стили.
- `src/components` - секции лендинга и UI-компоненты.
- `src/data/projects.ts` - данные проектных карточек.
- `src/data/skills.ts` - навыки и шаги рабочего процесса.
- `src/data/contacts.ts` - контактные ссылки.

## Деплой на Vercel

1. Подключить репозиторий к Vercel.
2. Оставить стандартные настройки для Next.js.
3. Запустить деплой из панели Vercel или через GitHub-интеграцию.
